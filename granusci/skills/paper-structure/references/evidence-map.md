# 证据地图（Evidence Map）——引用-主张对齐硬门

移植自 evidence-driven-writing（research-writing-assistant）。写 Introduction /
Related Work / 任何带引用的背景段之前，必须先建证据地图。**没有地图不写作。**

## 为什么

paper12 的教训：论文只有 6 篇引用——不是数量问题，是没有"引用-主张"对齐
机制：写了主张 → 没有对应文献 → 要么删主张要么硬写空话。证据地图把因果倒
过来：先盘点文献能支撑什么主张，再决定写什么。

## 地图模板（每条可用文献一行）

| 文献 ID | 引用键 | 类型 | 摘要级发现 | 可用事实 | 支撑的主张 | 引用槽位 | 风险 |
|---|---|---|---|---|---|---|---|
| dai2020 | dai2020 | 期刊 | GPSI 偏析指数 | 仅描述不预测；单一材料验证 | "指数是描述性的" | Intro-张力 | - |
| ... | | | | | | | |

## 规则

1. **一条引用支撑一个具体主张**，不是模糊的领域陈述（"偏析很重要 [1-8]"不合格）；
2. 只用**真实检索记录中出现过**的信息（标题/摘要/DOI 元数据/精读摘要）——
   知识库和文献工具里没有的东西不写（防幻觉引用，审稿失败模式 2）；
3. 弱支撑标 `Risk: indirect`——正文使用时必须降语气；
4. **充分性判据**：研究主线各有一席（现象发现史/机制之争/定量先例/方法线），
   总量不足时**回到文献工具补检索再写**，不用稀疏文献硬写；
5. 正文写作时逐段核对：每段引用的文献都出现在地图里，地图里标了 Risk 的
   主张措辞必须相应降级。

## 与 GranuSci 管线的衔接

- 素材来源：lit_survey 综述 / OpenAlex 元数据 / deep_read_paper 精读摘要 /
  kb_search 知识库（domain-knowledge 里的经典文献可直接入图）；
- gap-mining 的缺口清单直接给出"张力"行的素材；
- 建图动作本身用 plot_script 风格的工具调用完成（或直接在消息里列 markdown
  表）——地图里的文献元数据必须与检索记录一致。
