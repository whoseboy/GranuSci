# 审稿质量评分细则（七维度完整锚点）

移植自 academic-research-skills 的 review_criteria_framework + quality_rubrics，
适配 GranuSci 的自主研究审稿场景（数值一致性与诚实性为新增维度）。

## 维度 1：原创性

| 级别 | 描述 |
|---|---|
| 5 杰出 | 提出全新的理论/方法/证据，可能改变领域方向 |
| 4 强 | 有明确的新洞察或新颖组合，填补特定研究缺口 |
| 3 合格 | 增量贡献，对现有知识的合理延伸 |
| 2 弱 | 与现有文献高度重叠，新贡献不清 |
| 1 无 | 基本重复已知内容 |

## 维度 2：方法严谨性

| 级别 | 描述 |
|---|---|
| 5 杰出 | 研究设计无懈可击，方法创新且执行完美 |
| 4 强 | 设计合理，方法得当，执行有少量改进空间 |
| 3 合格 | 方法基本可接受，但存在设计或执行局限 |
| 2 弱 | 方法有显著缺陷，影响结论可信度 |
| 1 不可接受 | 方法根本不适合回答该研究问题，或含严重错误 |

## 维度 3：证据充分性

| 级别 | 描述 |
|---|---|
| 5 杰出 | 证据丰富、多元、有说服力，超出预期 |
| 4 强 | 证据充分支撑全部主要主张 |
| 3 合格 | 大部分主张有证据支撑，少数需补充 |
| 2 弱 | 关键主张缺乏充分证据 |
| 1 不可接受 | 主张与证据严重脱节 |

## 维度 4：论证连贯性

| 级别 | 描述 |
|---|---|
| 5 杰出 | 论点清晰，逻辑严密，结构优雅 |
| 4 强 | 论证流畅，偶有小逻辑跳跃 |
| 3 合格 | 基本连贯，但部分段落间衔接不清 |
| 2 弱 | 多处逻辑断裂，读者难以跟随论证 |
| 1 不可接受 | 论证混乱，核心主张无法辨认 |

## 维度 5：写作质量

| 级别 | 描述 |
|---|---|
| 5 杰出 | 学术语言精准流畅，堪称写作范本 |
| 4 强 | 语言清晰，偶有不影响理解的小瑕疵 |
| 3 合格 | 总体可读，有语法或用词问题 |
| 2 弱 | 语言问题频繁，影响理解 |
| 1 不可接受 | 语言问题使读者无法理解内容 |

## 维度 6：数值一致性（GranuSci 特有）

| 级别 | 描述 |
|---|---|
| 5 杰出 | 全部数值在工具记录中有出处；比较性结论的方向与数值一致 |
| 4 强 | 个别数值属格式差异（舍入/百分数/绝对值），实质均可溯源 |
| 3 合格 | 少数派生数值缺工具记录，但关键结论数值完整 |
| 2 弱 | 多个关键数值无法溯源，或比较结论方向存疑 |
| 1 不可接受 | 存在凭空数值，或比较性结论方向错误 |

## 维度 7：诚实性（GranuSci 特有）

| 级别 | 描述 |
|---|---|
| 5 杰出 | 失败、模糊点、局限如实报告且定位准确 |
| 4 强 | 局限报告完整，个别失败处置记录缺失 |
| 3 合格 | 局限有报告但流于表面 |
| 2 弱 | 明显回避不利结果或粉饰失败 |
| 1 不可接受 | 掩盖关键失败或误导性表述 |

## 决策映射

综合七维度（第一层失败模式排查任一未过 = 直接拒收，不进入打分）：
- 多数维度 ≥4 且无 ≤2：倾向通过
- 存在维度 =2：须修改（重点修复该维度对应问题）
- 两个及以上维度 ≤2 或任一 =1：拒收
