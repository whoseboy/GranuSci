# 审稿意见响应（修改轮专用）

## 原则

修改轮是**又一次研究循环**，不是文案工作：major 意见常要求补实验/补分析，
决策路径与研究轮相同（假设层+账本纪律全程适用）。response letter 的质量
=审稿人对修改诚意的主要判断依据。

## 流程

### 1. 意见解析（每条拆到原子级）

逐条编号（R1.1/R1.2…审稿人分头），每条标注：
- **类别**：major（影响结论有效性）/ minor（表述/细节）/ misunderstanding
  （审稿人误读——须礼貌澄清+检查是哪句表述导致的误读）/ out-of-scope
  （超出本研究范围——诚实说明并列入 future work）
- **要求动作**：补实验 / 补分析 / 改表述 / 补引用 / 澄清
- **成本估计**：机时/工作量

### 2. 补实验决策表

| 意见类型 | 决策路径 |
|---|---|
| 直接可补且预算内 | 补，走标准研究循环（假设层+仿真门+账本） |
| 可补但超预算 | 补最小充分版本（能回应意见的最小设计），预算说明进 response |
| 多个意见指向同一缺口 | 合并成一个补实验（response 里说明合并逻辑） |
| 与已有证据矛盾的意见 | 不盲从——摆证据、礼貌反驳（引用自己的数据/工具记录） |
| 互相矛盾的两个审稿人 | 各自回应，编辑信里请编辑仲裁（不私下选边） |

**纪律**：补实验同样走账本与审计门——修改轮的新数字同样必须可溯源。

### 3. Response letter 骨构

每条意见的标准回复单元：

```
R1.2（major）：审稿人指出 XX 问题。
回复：感谢指出。我们 [补了实验 Y / 补了分析 Z / 修正了表述 / 澄清如下]。
[新证据一句话+数字锚点]；修改见正文第 X 节（改动处已标黄）。
[如是反驳：我们理解审稿人的关切，但基于以下证据我们认为…]
```

- 逐条对应、不合并吞掉小意见、不回避（"未采纳"也要给理由）；
- 开头一页总述：主要修改清单（审稿人 30 秒内看到诚意）；
- 语气：专业、感谢、不谄媚、不对抗——被误解时先自查表述。

### 4. 修改稿纪律

- 正文修改处标注（diff/高亮）；
- 新增数字走完整审计链（与首轮同标准）；
- 新增引用走 litx 管线（cite_id 制不因修改轮放松）；
- 若 major 修改改变了摘要主张：摘要-结论-response 三处同步。
