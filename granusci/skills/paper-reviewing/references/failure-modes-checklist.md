# AI 研究失败模式检测清单（审稿实操版）

源自 Lu et al. (2026). Towards end-to-end automation of AI research. *Nature* 651,
914-919（AI Scientist 团队对自己已发表论文的失败分析）——他们观察到：这些失败
**看起来都像胜任的工作**——幻觉实验结果与真实结果读起来一样。本清单把七种模式
转成审稿时的逐项质询。

## Mode 1: 实现 bug 通过 AI 自审

**症状**：分析代码有静默错误（错位、静默除零、类型强制、错误标志），产出
数值上合理但科学上错误的结果；AI 看输出"没明显问题"就收编进论文。

**审稿质询**：
- 每个数值结果：工具记录里有产出它的完整调用吗？返回状态是 ok 吗？
- 效应量有没有可疑地圆整（恰好 0.5、恰好 2 倍基线、恰好零方差）？
- 误差棒/区间在不同条件下是否本应变化却完全相同？
- 有没有"结果太好"的段落——完美得不像这个噪声水平的仿真该有的？

## Mode 2: 幻觉引用

**审稿质询**：
- 每条 \cite 键对应 thebibliography 条目吗？
- 每条参考文献在文献检索记录（lit_survey / OpenAlex / 精读记录）里真实出现过吗？
- 文献被赋予的主张与检索记录中的摘要/精读摘要一致吗（张冠李戴检测）？
- 参考文献条目的元数据（作者/年份/期刊/DOI）与检索记录一致吗？

## Mode 3: 幻觉实验结果

**症状**：结果不对应任何实际跑过的实验——数字被不同方式平均、来自崩掉的
run、或为匹配叙事而编造。

**审稿质询**：
- 每个 "X% 提升/降低/改善"：工具记录里有原始数和计算过程吗？
- "我们跑了 N 个工况/种子/样本"：实际提交的 job 记录数是 N 吗？
- 表格里的数字：能指到 responses.csv 或等价产物吗？
- 论文的"验证/对照"声明：对应的验证调用真的存在吗？

## Mode 4: 图文断层

**审稿质询**：
- 数一数：caption 宣称的数据点数、正文枚举的工况数、图上实际的标记数——三者一致？
- 图注声称的符号/颜色编码与图上实际画的系列一致吗？
- caption 里引用的数值（如拟合参数）与图上呈现的数据在同一量级吗？

## Mode 5: 过度声明（证据-语气失配）

**症状**：结论措辞超出证据强度——证据只表明"与假设一致"，结论写成"证明/确立"。

**审稿质询**：
- 逐条结论问：证据链断在哪一步？断点之前的部分最多支撑什么措辞？
- 机制结论：替代机制被排除了吗，还是只是没观测到？
- 普适性结论：验证范围（参数域、几何、工况数）覆盖声明范围了吗？
- 首次/新发现声明：有查新记录支撑吗？
- 规范措辞阶梯：is consistent with / suggests / supports > demonstrates /
  proves / establishes——用词站在证据能撑住的那一级了吗？

## Mode 6: 内部计数/数字矛盾

**审稿质询**：
- 全文抽取关键计数（总工况数、有效样本数、分区数、符号确认点数），在
  摘要/正文/图注/结论各处比对——完全一致？
- 同一物理量在不同位置的数值（正文 vs 图注 vs 表格）一致吗？

## Mode 7: 方法学从记忆构建

**症状**：Methods 写的是该类研究的"典型做法"（LLM 训练记忆），而非本研究
实际执行的做法。

**审稿质询**：
- Methods 的每个步骤（协议参数、分析设置、判据选择）都能在工具记录中
  找到对应执行吗？
- 有没有 Methods 描述了但没执行的操作（如声称的鲁棒性检查）？
- 反向：有没有执行了但 Methods 没写的重大操作（数据清洗、剔除）？
