# Results 证据链原型与主张升级模式库

移植自 nature-skills 的 results-discussion。Results 不是实验流水账——
是主张的逐级确立。选择证据链原型 = 选择论证策略。

## 四种证据链原型（按论文主张类型选）

### 1. 机制确立链（mechanism establishment）
`现象观测 → 机制假设 → 鉴别性实验（假设预测 X，做 X 的定向测试）→ 排除替代 → 机制结论`
适用：核心贡献是"解释了为什么"。
关键：鉴别性实验必须是**假设之间可区分**的（如对流 vs 空隙填充——变壁摩擦
会强烈改变前者而几乎不影响后者；没有区分度的"验证"不算）。

### 2. 定量律确立链（quantitative law）
`现象 → 数据系统采集 → 函数形式拟合 → 拟合质量与残差结构 → 预测验证（样本外）→ 适用域
适用：核心贡献是"给出了定量关系"。
关键：预测验证必须真样本外（留出工况/新参数点），样本内一致性检查要如实
标注为 in-sample closure（paper12 一轮审稿教训）。

### 3. 边界/相图测绘链（regime mapping）
`参数空间系统扫描 → 相界定位 → 相界两侧的代表性证据 → 相图 → 判据形式`
适用：核心贡献是"划分了领域"。
关键：相界上的点要加密（边界的不确定性来自采样密度）；每个相区至少一个
代表性工况的深入证据。

### 4. 方法效力链（method efficacy）
`基线 → 提出方法 → 对照比较 → 消融（各组件贡献）→ 鲁棒性 → 失效模式`
适用：核心贡献是"新方法"。
关键：消融不是可选项——没有消融的效力声明过不了审。

## 升级链写作纪律

1. **同层不重复**：同一主张的第二次演示不算新小节（paper12 的 148 张图
   大半是同层重复——该删）；
2. **每个证据单元以推断收尾**：一段证据 → 一句"这确立了什么"（局部推断），
   全篇推断在 Discussion 升华；
3. **局部解释门**：Results 里的解读只允许"这组数据直接显示的"——超出
   数据直接含义的解释去 Discussion；
4. **主张计数一致**：摘要/图注/结论声称的样本数、点数、工况数——与正文
   枚举、图上实际呈现完全一致（paper12 二轮审稿教训：13 vs 9）。
