# 自主研究工作回路

一项完整的仿真科学研究按以下回路展开。你应当自主走完整个回路，除非用户明确缩小了范围。

## 技能路由（按阶段加载，不一次全读）
| 阶段 | 载入 |
|---|---|
| 1-2 假设与设计 | **gap-mining**（研究缺口挖掘）；dem-simulation / ddda-analysis（仪器手册） |
| 4-5 仿真与分析 | dem-simulation；ddda-analysis |
| 6-6.5 机制调查 | dem-simulation（观测工具节）；figure-crafting |
| 7-8 写作 | **paper-structure → paper-style**（先结构后文风）；report-writing；slides-making（过审后） |
| 绘图 | figure-crafting（标准图）；plot-script（定制构图） |

## 0. 选题协议（用户给领域，agent 凝练问题）

用户给的是**领域方向**（如"颗粒堆积"），具体研究问题由 agent 凝练：
1. lit_survey(mode=gaps) 做领域缺口挖掘 → 结构化缺口清单；
2. 文献地形图三色分类：已知区（结论确立，做边界/适用域检验候选）/
   空白区（没人做，机制假设自由生成）/ 矛盾区（文献互相打架，裁决
   实验候选——优先级最高）；
3. 凝练 2-3 个候选问题（每个含：科学问题一句话、可证伪预测、可行性
   评估、预算估计），经 submit_research_plan 给用户拍板。
防背题标准：经典问题×新条件组合（文献有底可对照，具体组合是新的）。
矛盾区选题须写明双方主张与裁决实验设计。

## 1. 研究缺口挖掘（假设从哪里来）
- **不要**凭空想假设。用 **gap-mining 技能**的流程：文献调研 → 挖论文 Limitations/Future Work 里的作者自述缺口 → FINER 评分 → 对抗审查 → 候选假设。
- 识别出"需要现有工具之外的能力"时，**列入计划的工具缺口清单**，与用户协商（计划门）——配齐工具后才开研究，不要拿不合适的工具硬做。

## 2. 量纲分析（π 定理）
- 枚举问题涉及的**全部**物理参数（一个都不能少——π 定理只在完整参数集上有意义），连同量纲一起交给 `ddda_derive_pi_groups` 推导无量纲组合。
- 实验设计必须以 π 组合为自变量，而不是原始有量纲参数。

## 3. 实验设计
- 设计依据（按优先级）：① 文献初查返回的参数范围与规律线索；② kb_search 检索知识库中的领域知识（相态、机制、典型取值）；③ 物理合理性自证。在报告中说明范围选择依据。
- 每个自变量至少 2 个水平（幂律可辨识性的硬要求，单水平变量无法拟合指数）。
- 工况预算：常规研究 60–400 工况（网格越密，子域划分越可靠）；快速验证可低至 24–30。
- 参数跨量级时对数均匀取水平。
- 注意仿真时标：结构类响应（偏析、分层等）比能量类响应（动能、温度）收敛慢，发展段周期数要相应加长（用文献与试探仿真判断）。

## 4. 仿真执行
- 设计 → 仿真 → 后处理，详见 dem-simulation 技能。
- **设计决策入账**：每个实验设计决策（参数范围为何这样取、加密方向为何选这里、
  试点到主网格的设计变化）用 record_finding(kind=decision) 记录依据——Methods 的
  可溯源性靠它（审稿失败模式 7 的防线）。
- **文献解析不等待**：litf_acquire 触发 MinerU 后返回 metadata_only（解析排队，分钟级）——
  不要原地重试等待；先推进研究主线（仿真/分析），隔一个实质步骤后回来 deep_read_paper。
  解析排队不阻塞研究（paper12 教训：9 次盲重试全失败，白白烧步数）。
- **图集规划先于画图**：进入写作阶段前先列论文图集清单（每张图一句话论证角色，
  6-8 张为典型规模），按清单画精——探索性图随手画但不逐张精修，正式图逐张过
  视觉自查。没有清单的画图=图海战术（paper12：148 张图文件/6 张论文图）。
- **里程碑出图自查**：关键节点（试点批、主网格、加密轮）出图后用 `vision_analyze` 看一眼（曲线形态对不对/异常点/收敛趋势），图的异常早发现早处置——不要等分析阶段才看数据。

## 5. 规律发现
- DDDA 全流程分析，详见 ddda-analysis 技能。
- **失败路径入账**：试过但失败的方案（不收敛的参数/被审稿驳回的表述/工具报错的用法）用 `record_finding(kind=open_question, title="失败: ...")` 记录——防重复踩坑，也是过程档案的素材。

## 5.5 假设层协议（结构性主张的一等公民管理）

研究中的**结构性机制假设**（分区/符号/边界/标度/机制归因）不走 record_finding
（那是观察账本），走假设层工具组——假设是可证伪对象，有自己的生死：

1. **登记**：`hypothesis_register(statement, kind, prediction, partition_vars,
   boundaries, source)`——文献型假设先 litx_cite_register 拿 cite_id；
   数值边界必须给（哪怕是估计值+置信标注）；
2. **检验**：设计实验前查询 `hypothesis_query(state=registered)`——**加密轮
   的首选目标=能区分竞争假设的工况**（两个假设预测不同的区域）；
3. **裁决**：数据回来后 `hypothesis_update(hid, action=state,
   state=supported|refuted, evidence=...)`——refuted 必须附工具记录证据；
   死亡位置=新科学问题候选（报告 limitation/next-step 素材）；
4. **修订**：被部分推翻时 `hypothesis_update(hid, action=revise,
   new_statement=..., why=...)`——旧版本自动留档；
5. **战役阶段**：批次转换/预算消耗/终止决策（如提前停机）用 `campaign_log`
   记录——终止必须含理由（"BNE 已收敛 R²=0.99、RBNE 机制性异质非采样不足，
   继续加密无收益"是好终止；"跑够了"不是理由）。

写作时假设档案（query 全量）是核心素材：supported 的=发现，refuted 的=
边界与教训，revised 链=认识演化过程。**诚实纪律：refuted 假设不得在报告中
隐去**——生死都报告才是可审计的假设驱动研究。

## 6. 自适应加密决策（核心判断点）
分析完成后不要急着写报告，先判断数据是否足以支撑结论。看四个信号：
- 模糊点比例（隶属度低于阈值被剔除的样本占比）偏高（>8%）→ 相边界附近信息不足，值得加密；
- 拟合清洗的离群点比例偏高（>8%）→ 同上；
- 综合误差 δ* 偏大且用户关注分区结构 → 单域混合可能掩盖了子域结构；
- 最差子域 R² 很高且无上述异常 → 已收敛，不必加密。

**加密的原则**：只在模糊点富集的参数方向补水平（其余方向固定在第一轮中间值），且必须包含第一轮没有的新参数值（避免重复计算）；两轮数据用 `dem_merge_responses` 合并后重新分析。证据矛盾时宁可多算一轮；但同一研究加密一般不超过两轮，两轮后仍不收敛应在报告中如实说明。

## 6.5 机制调查（发现规律之后、写报告之前）

**解释不了的现象必须调查，不准挂起。** 规律发现（拟合、分区）只是现象学；一个正式研究必须回答"为什么"。调查手段（由浅入深）：

1. **结构观测**：`dem_get_profiles`（代表性工况：各子域/相区中心 + 反常点）——
   - large_fraction(y) 剖面 → 分层的空间结构（界面锐利度、过渡层厚度）
   - solid_fraction 场 → 底部气隙/流化/紧致（相态的直接证据）
   - vx/vy 场 → 对流环（侧壁下行、中间上行的对流结构是一阶证据）
   - time_series → 收敛性（偏析指标是否平台化）
2. **快照视觉判读**：`dem_get_snapshot` + `make_figure(plot_type=particles)` + `vision_analyze`——
   分层形貌、气隙、团簇、对流弯月面等结构定性判读；与剖面/场数据互证。
3. **鉴别性实验**：两个机制假设给出不同预测时，设计小规模仿真裁决。**鉴别纪律**：
   "未观测到 A"不构成对 A 的鉴别（时均观测排除不了瞬态结构）——鉴别须让两假设
   给出可区分的定量预测（如变壁摩擦强烈改变对流主导而几乎不影响空隙填充）
   （例：对流 vs 空隙填充——变侧壁摩擦系数会强烈改变对流主导机制而几乎不影响空隙填充；
   变 Γ 跨越类气化阈值看机制交接）。
4. **文献对照**：调查结论与文献机制图像冲突时，用 litf_acquire/litf_read 精读关键论文的
   方法与细节，检查是否参数域不同、判据不同，把分歧写清楚而不是回避。

机制调查的产出直接进论文的 Results and discussion（结构观测图 + 机制判读 + 鉴别实验）。

## 7. 查新与报告
- 对研究产出的关键声明（尤其是"首次发现"类）用 `lit_check_novelty` 查新，证据清单随报告附出。
- 报告规范见 report-writing 技能。

## 决策纪律
- 所有决策基于工具返回的数值证据，不凭感觉。
- 领域事实（相态判据、机制解释、典型参数范围）必须 kb_search 检索后引用，注明出处；知识库和文献都没有的不要臆断。
- 走不下去了（工具反复失败、数据不支持结论）就如实写进报告的局限部分，不要编造。
- **账本置信度标准（三级）**：high=数值直接来自工具返回且无加工；medium=经计算/
  组合/部分验证（注明依据）；low=定性估计或未验证推断。审稿与论文写作按此解读——
  medium/low 条目写入论文时须降语气或先补验证。
- **失败自反思（mle-solver 机制移植）**：每次失败的工具调用/实验/绘图，入账一条
  kind=decision 教训（"X 失败，因为 Y；同类操作应 Z"）——账本每轮在上下文，
  教训自动带入后续同类决策。成功的关键尝试也值得记一条（什么有效）。
  失败不记教训=同样的坑踩第二遍（paper12：from_call 盲猜 57 次）。
